# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, no harassment. Unacceptable behavior can be reported to the maintainers at **seif.ibrahim@iseif.dev**. Maintainers will review and respond confidentially, and may take any action they deem appropriate, up to and including a ban.

The full text of Contributor Covenant 2.1 governs; see the link above.
